# PokeAPI vježba

1. Uključite Handlebars biblioteku na stranicu koristeći CDN.
2. Proučite [Pokémon API](https://pokeapi.co/).
3. Kreirajte request (fetch, XHR ili drugom metodom) koji dohvaća prvih 20 Pokémon vrsta žute boje.
4. Kreirajte stiliziranu HTML tablicu dobivenih rezultata koristeći Handlebars.
5. Lista mora sadržavati:
   - redni broj
   - ime vrste, koje je ujedno link na API endpoint s više informacija o vrsti
